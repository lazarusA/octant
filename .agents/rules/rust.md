# Rust & Octant Guidelines

The rules live in one place, `AGENTS.md` at the repository root: Rust quality and checks
(no `unwrap()`, and `expect()` only where the app cannot run without the value),
architecture and file limits, the zero-allocation UI and render loop rules, and licensing.
Each subsystem's details are in the skills it lists (`.agents/skills/`), with their
reference files; Rust best practices in `rust-skills`.
